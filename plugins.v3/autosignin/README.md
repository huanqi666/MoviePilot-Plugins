# 站点自动签到（AutoSignIn）

MoviePilot 插件：自动模拟登录并签到 PT 站点。

本目录是**上游 thsrite/AutoSignIn 3.0.10 的补丁版**，只改了一处，其余逻辑与上游一致。

## 与上游的差异

签到与模拟登录的 HTTP 请求增加了超时重试：

| 请求 | 上游 | 本版 |
|---|---|---|
| 签到（`__signin_base`） | 失败直接判定"签到失败，无法打开网站" | 最多 3 次，首次用原超时，重试用 20s，间隔 5s |
| 模拟登录（`__login_base`） | 失败直接返回失败 | 最多 2 次，同上 |

起因：整点定时任务高峰时，个别站点会偶发 TLS 握手挂起，`RequestUtils.get_res` 返回 `None`。上游此时直接判失败，随后只做模拟登录、不重试签到，当天记成"登录成功，签到未确认"且不再重试。

现在偶发挂起会被重试兜住，晚间兜底仍由插件自带的 `retry_keyword` 配置负责。

## 版本

- `3.0.10.1` — 上游 3.0.10 + 上述重试补丁
- `3.0.6.1` — 上游 3.0.6 + 同一补丁（已废弃）

上游发新版本后需要把新代码合并进来并递增版本号；只想跟随上游、不需要重试时，直接装官方市场的 AutoSignIn。

## 站点支持

`sites/` 下为各站点实现，与上游保持同步。
